# MT-dos
A easy dos like program

MT-DOS 是一个用 tkinter 编写的虚拟 DOS / 终端操作系统模拟器：虚拟磁盘与分区、注册表、虚拟进程、光盘、局域网文件互传、Wikidot 站点浏览、音频工具、科学计算器等，全部通过终端命令操作。

*MT-DOS is a virtual DOS / terminal-OS simulator written in tkinter: virtual disks & partitions, a registry, virtual processes, optical discs, LAN file transfer, Wikidot browsing, audio tools and a scientific calculator — all driven by terminal commands.*
